# دیتاتایم — سایت معرفی (Landing Page)

سایت معرفی اپلیکیشن مدیریت مجموعه **دیتاتایم** با طراحی Liquid Glass خاکستری به سبک iOS.

## اجرا

فایل `index.html` را در مرورگر باز کنید — هیچ build یا وابستگی لازم نیست.

## انتشار با GitHub Pages

1. `Settings` → `Pages`
2. Source: **Deploy from a branch** → شاخه `main` / پوشه `root`
3. آدرس نهایی: `https://amirsaeedidev.github.io/datatime-landing`

## اتصال فرم درخواست

متغیر `FORM_ENDPOINT` در انتهای `index.html` را به آدرس وب‌هوک خود
(Formspree، Google Apps Script، بات تلگرام و…) تغییر دهید.
تا زمانی که خالی باشد، فرم فقط حالت موفقیت را شبیه‌سازی می‌کند.

## ساختار

- تک‌فایل `index.html` (HTML + CSS + JS)
- فونت: [Vazirmatn](https://github.com/rastikerdar/vazirmatn) از CDN
- بدون فریم‌ورک، بدون build
